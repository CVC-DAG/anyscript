Required format: query_image, retrieved_image, similarity

CSV Format Requirements

Your submission CSV must follow this exact structure:

Required Columns

Column Name Data Type Description
query_image String Query document identifier (page or book ID)
retrieved_image String Retrieved document identifier from training set
similarity Float Similarity score (typically between 0 and 1)

Example CSV Structure

query_image,retrieved_image,similarity
query_page_001,train_page_1234,0.892
query_page_001,train_page_5678,0.763
query_page_002,train_page_3456,0.915
Important Notes:
  • CSV must contain exactly 3 columns - no more, no less
  • Column order must match: query_image, retrieved_image, similarity
  • No extra columns will be accepted
  • File size limit: 16MB maximum
  • Similarity scores should typically range between -1 and 1
